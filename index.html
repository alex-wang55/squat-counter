      How scoring works
      • Each rep scores by depth: Perfect 100, Great 70, Good 50, Shallow 10.
      • Good-or-better reps in a row build a combo multiplier: ×1.5 at 5, ×2 at 10, ×2.5 at 15, ×3 at 20. A shallow rep resets it.
      • Each run starts with a one-second calibration. Stand tall so the game learns your straight-leg position. Depth is measured from there.
      • Space plays, Esc ends a run.
